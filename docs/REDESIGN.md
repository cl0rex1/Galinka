# Galinka 0.3: анализ и изменения

До изменений приложение уже поддерживало регистрацию, личные чаты, группы, файлы, реакции и SSE. Основные проблемы интерфейса: постоянная третья колонка, повторяющиеся рекламные подписи, отведённое под модуль место в списке чатов и над вводом, светлая тема без выбора, одноуровневое поле сообщения. Мобильная установка ограничивалась PWA, фоновых пушей не было. Настольная оболочка зависела от загрузки интерфейса с сайта, а установщик включал ненужные серверные зависимости.

Изменения:

- Список чатов и переписка стали основными колонками. Сведения и участники открываются отдельно.
- Полностью обновлены стили, отступы, аватары, поля ввода и состояния выбора. Сокращены подписи, формы и страница загрузок, удалены декоративные блоки.
- Светлая, тёмная и системная темы используют общие токены. Выбор хранится локально и доступен на экране входа.
- Поле сообщения растёт до восьми строк. Черновики сохраняются при переключении чатов в рамках сеанса.
- На телефоне сохранены отдельные экраны списка и разговора. Android Back закрывает панель/поиск/диалог и возвращает к чатам. Учтены safe areas и reduced motion.
- Добавлены нативный Android-проект, подписанная APK-сборка, push-регистрация и серверная очередь Firebase. Пока Firebase не настроен, уведомления не запрашиваются.
- Настольные сборки содержат интерфейс и обращаются к существующему API. Клиент и серверные зависимости упаковываются отдельно.
- Для Arch Linux используется системный `electron44`: пакет обновляется через pacman без второй копии Electron. Windows сохраняет обновления из GitHub Releases.

Не менялись протокол сообщений, модель аккаунтов и формат переписки. Миграция добавляет только таблицы устройств и push-очереди. Сквозного шифрования нет. Известные ограничения MVP — локальный rate limiter и файловое хранилище — остаются прежними.
