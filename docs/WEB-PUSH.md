# Web Push

Galinka 0.5 использует стандартные зашифрованные Web Push для браузеров и установленных PWA. На iPhone/iPad требуется iOS 16.4+ и установка на экран «Домой». В Safari вкладке приложение покажет инструкцию установки. Разрешение запрашивается только кнопкой пользователя.

Один раз создайте пару VAPID-ключей в приватном терминале:

```sh
umask 077
node -e 'process.stdout.write(JSON.stringify(require("web-push").generateVAPIDKeys()))' > web-push-keys.private.json
```

Сохраните ключи в менеджере секретов и добавьте в `.env`:

```dotenv
WEB_PUSH_PUBLIC_KEY=<publicKey>
WEB_PUSH_PRIVATE_KEY=<privateKey>
WEB_PUSH_SUBJECT=https://mess.quiby.me
```

`compose.yml` передаёт эти значения приложению. В импортированном приложении CasaOS добавьте их также в environment управляемого compose. Пересоздайте только app. Приватный ключ не должен попадать в Git, клиентскую сборку, скриншоты или логи. Сохраняйте ту же пару при обновлении: смена ключей требует повторной подписки устройств.

Войдите в Galinka → Настройки → Уведомления → включите переключатель и разрешите уведомления системе. `GET /messenger/push/status` после входа показывает `browserAvailable:true` и публичный ключ; приватный ключ API не выдаёт.

Подписка привязана к текущей сессии. Выход и отзыв сессии прекращают доставку. Выключенные уведомления чата учитываются на сервере. Текст сообщения не передаётся провайдеру в открытом виде; уведомление содержит только общее «Новое сообщение» и идентификатор чата. Очередь доставки хранится в PostgreSQL, недействительные подписки удаляются при ответах 404/410. Поддерживаются известные HTTPS-адреса Apple, Mozilla, Google и Microsoft; произвольные адреса сервер не принимает.

Проверка доставки: включите уведомления, сверните приложение и отправьте сообщение с другого аккаунта в чат без отключённых уведомлений. Нажатие должно открыть этот чат. Затем выключите уведомления и убедитесь, что новые сообщения больше не вызывают уведомлений. Системный режим «Не беспокоить», ограничения батареи и запреты браузера могут подавлять показ.

На настольных клиентах используется системное уведомление Electron и активное соединение с сервером. Закрытие окна сохраняет приложение в трее, если он доступен; команда «Выйти» полностью завершает процесс. Это отличается от Web Push, который доставляется системной службой браузера.
