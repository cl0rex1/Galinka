# Промпт: 0.22.0 — боты и администрирование

Ты работаешь над мессенджером Galinka. Сначала прочитай [`docs/prompts/00-context.md`](00-context.md) и [`docs/DESIGN.md`](../DESIGN.md), затем раздел «0.22.0» в [`TASKS.md`](../../TASKS.md).

## Что есть сейчас

- Бот Неля отвечает на «@неля …» в чатах, где она включена (`server/nelya.ts`, переключатель в профиле чата). Повтор поведения для демо лежит в `src/demo.ts`.
- Админка: `src/Admin.tsx`, `src/AdminInvites.tsx`, `src/AdminMonitor.tsx`. Роль `users.role = 'admin'`, выдача ролей через `npm run admin:grant`.

## Задача

1. **Команды Нели с подсказкой при вводе `/`.** Список команд появляется над полем, как подсказка упоминаний (`mentionOptions` в `useComposer.ts`). Выбор стрелками и Enter. Команды: напоминание («/напомни через 2 часа …»), «кто свободен» (опрос с вариантами времени), жеребьёвка участников.
2. **Открытый API для ботов и вебхуки.** Токен бота выдаёт админ. Бот пишет только в чаты, куда его добавили. Вебхук подписан HMAC. Лимиты частоты и описание API лежат в `docs/BOTS.md`.
3. **ИИ-помощник: пересказ пропущенного.** Только по кнопке. Модель и ключ задаёт владелец в настройках сервера. Отправка переписки во внешний сервис требует явного согласия в чате и видна участникам.
4. **Админка:** жалобы на сообщения и людей с очередью; журнал действий администратора; статистика (активные пользователи, сообщения, объём файлов); квоты на пользователя (сейчас 500 МБ записаны в коде); просмотр и завершение сессий пользователя; режим обслуживания и срочное объявление; настройки сервера из интерфейса (лимиты, регистрация, бот).

## Ограничения

- Админские обработчики проверяют роль на сервере. Каждое действие администратора пишется в журнал.
- Перед удалением или блокировкой показывается, что именно будет затронуто. Необратимое подтверждается через `Confirm`.
- Таблицы админки на телефоне превращаются в карточки или прокручиваются вбок, но не сжимаются.

## Готово, когда

- Серверные тесты покрывают права (не-админ получает 403), подпись вебхука, лимиты бота и каждое админское действие с записью в журнал.
- Браузерный тест проходит подсказку команд в демо-режиме.
- В `TASKS.md` отмечены сделанные пункты.
