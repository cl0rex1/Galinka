# Промпт: 0.21.0 — приложения и платформы

Ты работаешь над мессенджером Galinka. Сначала прочитай [`docs/prompts/00-context.md`](00-context.md), затем раздел «0.21.0» в [`TASKS.md`](../../TASKS.md), [`docs/ANDROID.md`](../ANDROID.md) и `capacitor.config.ts`.

## Задача

1. **P1. Нативная сборка для iPhone через Capacitor.** Добавь платформу iOS, push через APNs (сервер `server/push.ts` сейчас знает FCM и Web Push), ответ из уведомления по образцу Android (`NotificationActionReceiver.java`), иконки и экран запуска. Если под рукой нет Mac с Xcode, подготовь всё, что собирается без него, и напиши пошаговую инструкцию в `docs/IOS.md`.
2. **Работа без сети.** Очередь отправки переживает перезапуск: сейчас неотправленное сообщение остаётся в памяти с кнопкой повтора (`useComposer.ts`, `sendText`). Последние чаты и сообщения читаются из кэша (IndexedDB) до ответа сервера. При перезагрузке данных старый вид не пропадает.
3. **Системное «Поделиться в Galinka»** на Android (intent filter, выбор чата) и iOS (share extension).
4. **Компьютер:** автозапуск и работа в трее с настройками (`desktop/main.cjs`). Подпись и нотаризация для macOS и подпись для Windows (`electron-builder.yml`) требуют сертификатов владельца: подготовь настройки и опиши, что нужно от владельца.
5. **Android:** виджет и ярлыки на чаты.

## Ограничения

- Номер версии, теги и публикация сборок меняются только по прямой просьбе владельца ([`AGENTS.md`](../../AGENTS.md)).
- Ключи, сертификаты и `google-services.json` в репозиторий не попадают (см. `.gitignore`).
- Веб-клиент и демо-режим продолжают работать без нативных модулей: каждую проверку возможности оборачивай в `platform.ts`.

## Готово, когда

- Android собирается и проходит JUnit: `cd android && ./gradlew :app:testDebugUnitTest :app:assembleDebug`, JDK 21.
- Очередь без сети покрыта браузерным тестом: отправка офлайн, перезагрузка, сеть вернулась, сообщение ушло один раз.
- В отчёте названо, что проверено на устройстве, а что только собрано.
- В `TASKS.md` отмечены сделанные пункты.
