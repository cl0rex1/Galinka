Galinka 0.3.2

- Подключён Firebase Cloud Messaging для Android.
- Войдите в аккаунт, откройте «Настройки → Уведомления», включите переключатель и разрешите уведомления Android.
- Автоматическая проверка Android теперь включает получение токена Firebase, если клиентская конфигурация присутствует в сборке.
- Клиентская конфигурация передаётся через GitHub Actions Secret; серверный ключ хранится только на CasaOS и не включается в APK.

APK подписан тем же ключом, что и 0.3.1: установите обновление поверх приложения. Для перехода с 0.3.0 по-прежнему требуется удалить старый APK и войти снова. Аккаунт и переписка сохраняются на сервере.

Push-уведомления требуют Google Play Services. Принудительная остановка приложения в настройках Android блокирует доставку до следующего запуска. Фоновые уведомления веб-версии и закрытого настольного приложения в этот выпуск не входят.
