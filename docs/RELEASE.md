Galinka 0.2 — приложение для своих.

- Настольные приложения Windows (NSIS), Linux (AppImage/DEB), macOS (Intel/Apple Silicon).
- Обновления из GitHub Releases: Настройки → Обновления Galinka.
- Сайт загрузки: https://mess.quiby.me, веб-версия: https://mess.quiby.me/app.
- API: https://api.quiby.me/messenger.
- Личные чаты, группы, файлы, реакции и модуль Неля.

Первый выпуск без сертификатов Microsoft/Apple. macOS: автоматическая установка обновлений требует подписанных сборок; доступна загрузка новой версии вручную. Linux: для обновления внутри приложения используйте AppImage. iOS/Android: установка PWA из Safari/Chrome. Нет сквозного шифрования, звонков и push-уведомлений.
