# Galinka 0.5.1

- Обновлённая переписка: компактные сообщения, ясные состояния кнопок, удобный мобильный ввод и спокойные переходы в светлой и тёмной теме quiby.core.
- Набор текста больше не перерисовывает ленту сообщений. Недавно открытые чаты возвращаются с загруженной историей и сохранённым местом чтения.
- Удержание сообщения на телефоне и правая кнопка мыши открывают действия. Свайп для ответа и возврат от края экрана сохранены.
- Предпрослушивание голосового перед отправкой, прогресс загрузки и понятный повтор при ошибке. Запись остаётся до подтверждения отправки; уже загруженный файл используется повторно.
- Новый аудиоплеер: перемотка, скорость 1×/1,5×/2×, отмена и повтор загрузки, скачивание записи.
- Сервер подготавливает голосовые в AAC/M4A для воспроизведения на iPhone и остальных платформах. Для прежних записей создаётся совместимая версия; оригиналы сохраняются.
- Исправлены подписи голосовых и фотографий в списке чатов, сохранение черновика при закрытии страницы и показ пустого архива.

Android: подписанный APK устанавливается поверх предыдущей версии с системным подтверждением. Windows: EXE. Linux: AppImage или DEB. Arch Linux: пакет для pacman. macOS: DMG для Apple Silicon и Intel. iPhone/iPad: Safari → https://mess.quiby.me/app → «Поделиться» → «На экран Домой».

Windows и AppImage могут автоматически загружать обновление в фоне; перезапуск выполняется по кнопке. Автозагрузка Android APK включается отдельно и работает, пока запущен процесс приложения. Неподписанные macOS-сборки обновляются через DMG, Arch/DEB — через новый пакет. Веб-приложение получает новую версию с сайта.

Для обработки голосовых при запуске сервера без Docker нужны FFmpeg и FFprobe. В Docker-образе они установлены. Аккаунты, переписки, прежние файлы и настройки уведомлений сохраняются.

Проверки включают отсутствие повторного рендера ленты при наборе, восстановление истории и прокрутки, удержание без конфликта со скроллом и повтор отправки голосового без дублирования загрузки. В браузерных тестах микрофон заменяется синтетическим сигналом; физические iPhone требуют отдельной проверки.
