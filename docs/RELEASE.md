Galinka 0.3.0

- Новый интерфейс переписки и списка чатов, короткие тексты, сведения о чате по запросу.
- Светлая, тёмная и системная темы.
- Многострочный ввод и сохранение черновиков при переключении чатов.
- Android 7+: подписанный release APK, встроенный интерфейс, кнопка «Назад», сохранение файлов через Android.
- Интеграция Firebase Push: регистрация устройств, очередь с повторами, переход в чат, отвязка при выходе.
- Windows x64: установщик EXE со встроенным интерфейсом.
- Arch Linux x64: пакет pacman с системным electron44.

Firebase ещё не настроен: в этом APK пуши не активны. Для включения нужны google-services.json, серверный ключ и пересборка; инструкция — docs/ANDROID.md.

Arch: sudo pacman -U ./Galinka-0.3.0-arch-x64.pkg.tar.zst
Windows EXE не имеет сертификата Microsoft. Обновление сайта/API выполняется отдельно. Сквозного шифрования и звонков нет.
