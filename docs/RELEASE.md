# Galinka 0.5.0

- Интерфейс в стиле quiby.core: нейтральная тёмная палитра Onyx, фиолетовый акцент, новая типографика, светлая тема.
- Анимации переходов и сообщений, отдельная настройка уменьшения движения и поддержка системной доступности.
- Свайп вправо для ответа на сообщение; жест от левого края возвращает к списку чатов, сохраняя текстовый черновик.
- Web Push для браузеров и PWA, включая iPhone/iPad на iOS 16.4+ после установки на экран «Домой».
- Системные уведомления настольного приложения, переход в чат по нажатию, работа в трее.
- Автоматическая загрузка обновлений Windows/AppImage; установка по явному нажатию, с защитой несохранённых вложений и правок.
- Обновления APK прямо в Android: прогресс загрузки, проверка пакета, версии и подписи, установка с системным подтверждением. Автозагрузку можно включить в настройках.
- Раздельная загрузка сайта, мессенджера и админки; жесты без React-перерисовки на каждом пикселе.
- Новые иконки, обновлённая страница загрузок с определением платформы.

Android: подписанный APK устанавливается поверх предыдущей версии; установка требует подтверждения Android. Windows: EXE. Linux: AppImage или DEB. Arch Linux: пакет для pacman. macOS: DMG для Apple Silicon и Intel. iPhone/iPad: Safari → https://mess.quiby.me/app → «Поделиться» → «На экран Домой».

Windows и AppImage могут автоматически загружать новую версию в фоне; перезапуск выполняется по кнопке. В Android автозагрузка APK включается отдельно и работает, пока запущен процесс приложения; может расходовать мобильный интернет. Galinka проверяет APK перед установкой, а Android запрашивает подтверждение пользователя. Неподписанные macOS-сборки обновляются через DMG, Arch/DEB — через новый пакет. Веб-приложение получает новую версию с сайта. Уведомления настольного приложения работают, пока процесс запущен, включая трей; полный выход прекращает их.

Ключ Web Push сохраняется на сервере и не входит в клиентские сборки. Существующие сообщения, аккаунты, файлы и Android-подпись сохраняются. Сквозное шифрование и звонки в этот выпуск не входят.

Скачанный APK проверен `apksigner`, подпись совпадает с прежним ключом, адрес API корректен, серверные секреты в APK отсутствуют.

Физическая доставка системного уведомления на iPhone и полная установка обновления поверх пользовательского Android-приложения требуют проверки на самом устройстве. Автотесты транспорта использовали подменённую сеть, а Electron smoke не показывал системных уведомлений пользователю.
