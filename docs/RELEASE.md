Galinka 0.3.1

- Android и настольные приложения подключаются к `https://mess.quiby.me/messenger`, без API Quiby и VPS.
- Исправлена маршрутизация API, файлов и живых сообщений при использовании встроенного интерфейса.
- Android APK проверяется на эмуляторе перед публикацией и выходит вместе с настольными установщиками.
- Сервер и сайт обновлены на CasaOS с сохранением аккаунтов, переписки и вложений.

Android: прежний ключ подписи 0.3.0 недоступен. Версия 0.3.1 использует новый постоянный ключ. Если установлена 0.3.0, удалите её, установите новый APK и войдите в свой аккаунт. Переписка хранится на сервере и сохранится. Последующие обновления будут подписываться новым сохранённым ключом.

Firebase ещё не настроен, поэтому push-уведомления отключены. Windows EXE не имеет сертификата Microsoft. Сквозного шифрования и звонков нет.
