- [x] P1 Прикрепление нескольких файлов сразу (до 10: выбор, перетаскивание, вставка; полоса миниатюр в поле ввода; голосовое, кружок и аудиофайл уходят по одному).
- [x] P1 Раздел «Медиа, файлы, ссылки, голосовые» в профиле чата (вкладки, подгрузка по 60, переход к сообщению; GET /api/chats/:id/media).
- [x] P2 Листание фото стрелками и свайпом в просмотрщике (видео — позже).
- [x] P2 Редактор перед отправкой: обрезка, поворот, рисование (`ImageEditor.tsx`; фото JPEG, PNG, WebP; GIF и видео не редактируются).
- [x] P2 Подпись к фото и видео прямо в окне прикрепления (`AttachDialog.tsx`: превью, карандаш к редактору, подпись, «Отправить»; «Свернуть» оставляет файлы в поле ввода).
- [x] P2 Обложки и размытые заглушки, чтобы лента не прыгала при загрузке картинок (клиент перед отправкой меряет фото и видео и делает превью 24 px; миграция 011: `files.width/height/thumb`). У старых сообщений размеров нет, они грузятся как раньше.
- [x] P2 Предел файла 100 МБ (было 20). Сжатие видео не в браузере, а на сервере сразу после отправки: видео больше 20 МБ перекодируется в H.264 до 1280 px и заменяет исходник под тем же id (очередь `media_jobs`, ffmpeg). В браузере нет кодировщика MP4 без сторонней библиотеки. На этой машине ffmpeg нет, перекодирование не запускалось.
- [x] P2 Докачка больших файлов после обрыва (файлы больше 4 МБ идут частями по 2 МБ: `POST /api/chats/:id/uploads`, `PUT /api/uploads/:id?offset=`, `POST /api/uploads/:id/finish`; «Повторить» продолжает с места обрыва; незаконченные загрузки удаляются через сутки).
- [x] P2 Кружки и видео из Firefox записываются в WebM: перекодируются на сервере в MP4 в той же очереди `media_jobs`; открытые чаты получают обновлённое сообщение. Не проверено с настоящим ffmpeg.
- [x] P2 Смена фронтальной и основной камеры прямо во время записи кружка (запись идёт через canvas, кнопка появляется при второй камере). На телефоне не проверено.
- [x] P2 Голосовое: пауза и продолжение записи, предпрослушивание (после «Готово»), запись удержанием (отпустил, и голосовое отправлено).
- [ ] P2 Волна громкости и распознавание речи в голосовых. Волна готова: во время записи живая, в сообщении 48 столбиков, сервер считает их ffmpeg для новых голосовых. Распознавания нет: нужен движок на сервере (например, whisper.cpp с моделью) — решение за владельцем.
- [x] P2 Голосовые и кружки подряд, мини-плеер над чатом (пауза, время, переход к сообщению, закрыть).
